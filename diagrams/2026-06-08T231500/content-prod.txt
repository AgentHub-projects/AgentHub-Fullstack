<h2>产品定位</h2><p>AgentHub 是一个<strong>以 IM 聊天为核心交互范式的多 Agent 协作平台</strong>。用户像使用飞书/微信一样，通过新建对话、发送消息的方式与不同 AI Agent 交互。平台接入 Claude Code、Codex、OpenCode 等主流 Agent 平台，通过统一适配器层屏蔽 API 差异，支持用户自建 Agent。</p><hr/><h2>核心设计理念</h2><h3>聊天即开发（Chat as Development）</h3><p>传统开发工具（IDE、命令行）学习曲线陡峭，AgentHub 将开发流程融入自然对话。用户通过自然语言描述需求，Agent 产出代码、文档、PPT 等产物，用户直接在聊天流中预览和迭代。这降低了 AI 辅助开发的使用门槛，让非开发者也能参与。</p><h3>群聊式多 Agent 协作</h3><p>在群聊模式中，用户 @ 多个 Agent，主 Agent（Orchestrator）自动理解意图、拆分任务、分派给子 Agent。多个 Agent 像群聊成员一样依次回复各自的产出。这种设计灵感来自飞书群聊的协作体验——用户不需要理解任务调度逻辑，只需描述需求并 @ 合适的 Agent。</p><h3>零配置上下文管理</h3><p>用户无需手动创建知识库、配置分块策略或选择嵌入模型。系统自动将每条消息、每个文件变更、每个产物转为向量索引，并在后续对话中自动检索相关上下文。这是 AgentHub 相比 Dify/Coze 等平台的最大差异化优势。</p><hr/><h2>与市面平台全面对比</h2><table><tr><td><p>维度</p></td><td><p><b>AgentHub</b></p></td><td><p>ChatGPT/Claude</p></td><td><p>CrewAI</p></td><td><p>Dify/Coze</p></td><td><p>Cursor/Copilot</p></td></tr><tr><td><p><b>交互范式</b></p></td><td><p>IM
