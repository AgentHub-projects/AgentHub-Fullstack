AgentHub Frontend Contract

前端与后端传输格式

前端与后端之间使用 REST + Socket.IO。REST 负责创建、读取和操作会话；Socket.IO 负责把后端已经落库或派生出的 session、event、artifact、file change、context 增量推送给浏览器。

来源：frontend/lib/agenthub-api.ts 来源：hub.controller.ts 来源：hub-realtime.gateway.ts
目录 1. 基础约定 2. REST API 3. Socket.IO 实时协议 4. DTO 类型 5. 支持取值 6. Artifact 内容读取

1. 基础约定

API Base

前端读取 NEXT_PUBLIC_API_BASE_URL，默认 http://localhost:3001。如果没有以 /api 结尾，前端会自动拼成 /api。

Socket URL

Socket.IO 连接使用去掉 /api 后的 base URL，path 固定为 /socket.io。

项目当前格式说明
HTTP 请求体JSON前端统一发送 Content-Type: application/json。
HTTP 成功响应JSON DTO由 Nest Controller 直接返回。
HTTP 失败响应{message}前端失败时优先读取响应 JSON 的 message，否则显示 HTTP status。
Socket transportswebsocket、polling前端允许降级 polling，重连次数为 5。

3. Socket.IO 实时协议

浏览器连接后，后端会先发 realtime.ready。前端在 connect 后发送 session.subscribe，后端把 socket 加入 session:<sessionId> 房间。

// client -> backend
event: "session.subscribe"
body: { "sessionId": "session-id" }

// backend -> client
event: "session.subscribed"
body: { "sessionId": "session-id" }

统一 envelope

{
  "type": "event",
  "sessionId": "session-id",
  "payload": {
    "id": "event-id",
    "runId": "run-id",
    "seq": 1,
    "eventType": "message.delta",
    "payload": { "text": "正在处理" }
  }
}
后端推送事件名envelope.typepayload DTO用途
hub:eventeventHubEventDtorun 过程事件。
hub:sessionsessionHubSessionDto会话标题、状态、lastRun 变化。
hub:artifactartifactHubArtifactDtoartifact 新增、更新、完成。
hub:file_changefile_changeHubFileChangeDto文件快照和 diff。
hub:contextcontextHubContextSnapshotDto上下文快照更新。
run.event无 envelopeHubEventDto兼容旧前端事件名。

旧事件 joinConversation 仍可订阅，body 为 {conversationId}，但新前端应使用 session.subscribe。

4. 主要 DTO 类型

DTO关键字段说明
HubSessionDtoid、title、status、metadata、lastRun会话列表和详情页顶部状态。
HubMessageDtorole、agentId、contentText、status、isPinned用户消息和最终 assistant 消息。
HubRunDtostatus、orchestratorAgentId、contextSnapshotId、errorCode一次用户请求触发的执行 run。
HubEventDtorunId、seq、eventType、speakerAgentId、payload实时过程和回放事实源。
HubArtifactDtoartifactKey、kind、storageKind、textContent、finalMarkdown、HTML、PDF、DOCX、图片、日志等产物。
HubFileChangeDtopath、changeType、beforeContent、afterContent、patch右侧 diff 面板的数据源。
HubContextSnapshotDtotokenBudget、tokenCount、snapshotJson、promptText当前 run 发送给云 Agent 前构造的上下文快照。
AgentTemplateDtodefaultProvider、systemPrompt、defaultCapabilitiesAgent 模板。
AgentInstanceDtotemplateId、provider、isDefaultOrchestrator、status实际参与会话的 Agent 实例。
BuildSessionDtostatus、context、agentTemplateIdAgent 模板 Builder 会话。
BuildMessageDtobuildSessionId、role、contentBuilder 对话消息。

6. Artifact 内容读取

前端通过 artifactContentUrl(artifactId) 拼出 /api/artifacts/:artifactId/content。

storageKind后端返回前端行为
inline_text直接返回 textContent，Content-Type 使用 artifact 的 mimeType。Markdown/text/log 直接渲染；HTML 可用 iframe srcDoc。
oss_object如果能生成 OSS 签名 URL，则 redirect；否则可能没有可用内容。PDF、image、DOCX 使用内容 URL 打开或预览。
remote_url当前读取逻辑会 redirect 到 storageUri。作为外部资源打开。
