8. 不同表之间的关联

Agent 模板与实例

agent_templates.id -> agents.template_id。模板保存默认提示词和能力，Agent 是可参与会话的实例。

会话成员

sessions 与 agents 通过 session_agents 多对多关联，复合主键是 (session_id, agent_id)。

会话主数据

sessions 一对多关联 messages、agent_runs、agent_events、artifacts、file_changes、context_items、context_snapshots。

Run 过程

agent_runs.id -> agent_events.run_id、artifacts.run_id、file_changes.run_id。事件以 (run_id, seq) 保证幂等。

Artifact 与文件变更

artifacts.id -> file_changes.artifact_id 是可选关联；文件变更也能只关联 run。

上下文索引

context_items.id -> context_embeddings.context_item_id。同一个 context item 对同一个 model 只能有一个 embedding。

简化关系图

agent_templates 1 ── * agents
sessions 1 ── * messages
sessions 1 ── * agent_runs
sessions * ── * agents        via session_agents
agent_runs 1 ── * agent_events
agent_runs 1 ── * artifacts
agent_runs 1 ── * file_changes
sessions 1 ── * context_items
context_items 1 ── * context_embeddings
sessions 1 ── * context_snapshots
sessions 1 ── * long_term_summaries
build_sessions 1 ── * build_messages

9. 当前不存在的旧设计表

以当前 schema.prisma 为准

旧设计文档里提到的以下表当前没有出现在 Prisma schema 中，写文档和开发时不要按它们假定已经存在。

旧设计表当前状态当前替代实现
downstream_sessions不存在真实下游连接保存在后端内存 Map；agent_runs.downstream_session_id 仅作为字段存在。
downstream_connections不存在连接状态不落库。
artifact_chunks不存在artifact.chunk 当前简化为累加 artifacts.text_content。
artifact_renders不存在当前没有独立渲染表；前端直接按 artifact kind 预览或打开内容接口。
session_contexts不存在长期摘要使用 long_term_summaries，运行快照使用 context_snapshots。
run_agent_mentions不存在用户消息的 mentions 保存在 messages.content_json.mentionedAgentIds，会话参与者保存在 session_agents。
